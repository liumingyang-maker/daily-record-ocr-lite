# 数据与隐私

上传图片、识别中间件、复核记录和 Excel 位于本机 `data/jobs/`。跨任务缓存位于
`data/cache/`，知识库位于 `data/knowledge.sqlite3`。视觉模型配置决定图片是否会
发送到本机或第三方端点；用户应阅读该服务的隐私条款。

API Key 位于环境或 `data/secrets.env`，不写入公开设置、任务或日志。卸载默认保留
`data/`。清缓存须运行 `scripts/cache_admin.py clear --yes`；删除识别数据必须由
用户明确决定并先备份。

## 配方历史与证据引用

用户确认整批结果后，客户、产品、日期、材料、数量、单位和工艺会追加到本机
`data/knowledge.sqlite3`。知识库只保存指向来源任务、来源配方和图片序号的引用，不复制
完整视觉模型原始响应。页面通过受限的任务文件路由显示原图证据。

知识历史采用追加语义：新的日期或修订会新增记录，不会覆盖旧记录。迁移旧知识库前会在
`data/backups/` 创建一次本地备份。任务目录中的 `review/finalization.json` 只包含最终结果
指纹、知识库记录编号和确认时间，不包含 API Key 或 Authorization Header。

## 保留与删除

- 删除 `data/jobs/<job-id>/` 会删除该任务的原图、中间结果、确认记录和 Excel，但不会自动
  删除已经追加到知识库的历史；这样可避免无意破坏业务时间线。
- 删除某条知识历史必须是用户明确发起的独立操作；不得因重新识别、更新程序或删除任务而
  级联删除。
- 删除 `data/knowledge.sqlite3` 会删除全部本地知识历史；执行前应同时备份数据库及
  `data/backups/`。
- 源码更新和未来的桌面安装包更新都必须默认保留整个 `data/`，不得回显或迁移明文 Key 到
  公共日志、测试快照、PR 或审计报告。
